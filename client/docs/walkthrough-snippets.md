# ⚡ Snippets Inteligentes

SynBio-LLVM incluye **37+ snippets** para acelerar tu diseño:

## Snippets Principales

| Prefijo | Descripción |
|---------|-------------|
| `tu:basic` / `tu` | Transcription Unit básica |
| `tu:regulated` | TU con promotor regulado |
| `toggle` | Toggle Switch completo (Gardner 2000) |
| `repressilator` / `repr` | Repressilator (Elowitz 2000) |
| `sensor` | Sensor-Reporter (promotor inducible + GFP) |
| `circuit` | Circuito genético completo |
| `killswitch` | Kill Switch de bioseguridad |
| `crispr:ko` | CRISPR knockout template |
| `bio:sensor` | Biosensor completo con kill switch |
| `bio:induction` | Experimento de inducción |
| `gene` | Definición de gen |
| `promoter` | Definición de promotor |

## Cómo usar
1. Escribe el prefijo en un archivo `.bio`
2. Presiona `Tab` para expandir
3. Usa `Tab` para navegar entre campos editables

## Tip Pro
Escribe `bio:` para ver snippets de biosensores y experimentos. Escribe `tu:` para Transcription Units.
