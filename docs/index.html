SynBio Studio

A synthetic biology IDE toolkit for genetic circuit design. Write a circuit in BioScript, compile it to SBOL and SBML, and run ODE or Gillespie simulation on your own machine.

Download the Windows release Browser preview on Hugging Face

The download is the zip attached to the latest GitHub release (SynBio-Studio-1.0.0-Windows-x64-Setup.zip on v1.0.3). The Hugging Face Space is a secondary preview, not the packaged application. Linux and macOS builds are from source.

What it is

SynBio Studio treats a genetic design as a program. The public repository contains a Rust compiler and language server, TypeScript libraries aimed at an editor, a local Python engine, and a small browser demo. The author is Jorge Guillem Najarro, an independent developer in Catarroja, Valencia.

The Electron sources of the Windows package are not in the repository. The VS Code extension entry point is empty, so cloning the tree and pressing F5 does not open a working editor. Headless tests cover the TypeScript functions that do not need VS Code. This page describes that public source.

What the public code does

  • BioScript compiler (synbio-lsp --compile-full). Parses a circuit and can emit SBOL, SBML, FASTA, GenBank, LLVM IR as text, an OpenTrons protocol script, and a Markdown protocol. The crate does not link against LLVM.
  • Language server. Completion, hover, and diagnostics over standard input and output.
  • SBOL and SBML checks. When pySBOL3 and libSBML are installed, the Rust tests validate those exports. Continuous integration installs the validators.
  • Local simulation. A FastAPI engine on 127.0.0.1 integrates ODEs with SciPy and runs Gillespie’s direct method. Gillespie propensities are constants, so Hill functions belong on the ODE route. GillesPy2 is used when that package is installed.
  • Optional scientific routes. Flux balance analysis needs COBRApy and a model file. Alignment needs MUSCLE or Clustal Omega. RNA folding uses ViennaRNA, or a Nussinov approximation. BLAST needs BLAST+ on the path. Promoter, codon, and CRISPR off-target models load only with their files.
  • TypeScript libraries. Codon optimisation, design-rule checks, a keyword biosafety scan, CRISPR guide search, cloning-strategy planning, thermodynamics, restriction sites, and a small flux-balance solver. The guide search is a short heuristic, not a genome-wide off-target screen. The biosafety scan matches substrings. It does not align DNA to a pathogen database.

ESMFold and the iGEM lookup call public web services. They are not offline. No laboratory validation is reported in this repository.

Examples

Two tutorials in the repository have exact commands and sample output.

  • Repressilator. BioScript for a LacI–TetR–cI ring, compiled with synbio-lsp, then an ODE repressilator and a seeded Gillespie cassette through the Python engine, with a plot.
  • CRISPR guides and a biosafety scan. SpCas9 guide search on a 117 bp EGFP fragment, then the keyword scanner on two BioScript files, including the cat substring hit inside the DNA.
