🧬 Instalar SynBio Python Engine

Paso 1: Verificar Python

Abre PowerShell y ejecuta:

python --version

Debes tener Python 3.9 o superior. Si no lo tienes, descárgalo de python.org

Paso 2: Ejecutar el instalador

En PowerShell, navega a:

cd "/workspace/client\..\python-engine"

Luego ejecuta:

start-server.bat

Paso 3: Verificar

El servidor se iniciará en http://127.0.0.1:8765

Recarga VS Code (Ctrl+Shift+P → "Reload Window") para reconectar.

⚡ Inicio Automático (Opcional)

Para que el servidor inicie automáticamente con VS Code, puedes crear una tarea en .vscode/tasks.json
